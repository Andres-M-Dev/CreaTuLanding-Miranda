# Proyecto final - Luis Andrés Miranda

Ecommerce desarrollado en React, Vite y Firebase.

## Descripción
Yggdralixir, un ecommerce de hidromiel artesanal y productos de cera de inspiración nórdica.

## Tecnologías
- React
- Vite
- React Router
- Firebase / Firestore
- React Toastify

## Funcionalidades
- Listado de productos por categoría y vista de detalle
- Carrito de compras con Context API
- Checkout con generación de orden en Firestore
